# memoria-e-decisoes

Estado: contrato planejado, sem implementação vinculada.

Identificar contexto pessoal, Imex ou Aluai antes de registrar. Preservar origem, data e diferença entre proposta e decisão. Buscar versão atual; explicitar quando informação estiver ausente ou antiga. Corrigir registros com rastreabilidade. Não importar conversas automaticamente sem integração autorizada. Produzir resumo mínimo para ferramentas externas, omitindo credenciais e dados privados. Registrar ideias de desenvolvimento no backlog e encaminhar para o módulo responsável; não executar a ideia como se fosse uma ordem de implementação.
