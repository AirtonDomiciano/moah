# Lições aprendidas

A primeira lição com evidência de teste está em [criação concorrente do SQLite](2026-10-28-criacao-concorrente-sqlite.md). Esta pasta não deve transformar hipóteses ou exemplos em ocorrências reais.

Para cada aprendizado comprovado, criar documento com:
- data, contexto e versão;
- sintoma e impacto;
- evidências sanitizadas;
- causa confirmada ou hipótese explicitamente identificada;
- correção e validação;
- prevenção e links para ADR, prompt ou teste afetados.

Problemas encontrados em projetos externos não são automaticamente incidentes do MOAH; identificar a origem se usados como referência. Não copiar logs privados para o repositório.
