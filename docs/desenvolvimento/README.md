# Desenvolvimento — como trabalhar no projeto

Responsabilidade: transformar uma tarefa em código verificado, com histórico claro.

- [Processo](processo.md): escopo, implementação, validação e documentação.
- [Padrões](padroes.md): orientações de código e testes.
- [Limites](limites.md): dados, permissões e ações autorizadas.
- [O que evitar](o-que-evitar.md): erros conhecidos de arquitetura.
- [Procedimentos](procedimentos.md): passos para tarefas recorrentes.
- [Prompts](../../cursror-dev/README.md) e [execuções](../../cursror-dev/execucoes/README.md).

Fluxo: escolher uma entrega → ler só o contexto relevante → implementar → testar → registrar resultado. Decisões importantes ficam na arquitetura; problemas comprovados ficam nas lições de operação.
